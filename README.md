## Projet ligue 1 live

Bienvenue sur le projet **Ligue 1 live**, mis à jour par Steeve Orville le Dimanche 22 novembre 2026. Ce projet a pour but de présenter l’analyse de donnée .

Ici nous allons analyser le tableau de la Ligue 1 ( championnat de France de football professionnel) . Les données de ce tableau sont actualisées automatiquement chaque semaine grâce à la technologie du scraping de données . Les graphiques bouge donc automatiquement chaque semaine .

Remarque : c'est une analyse de données simple donc il n'y a pas de machine learning à la fin .
